# Совместная работа агентов

В проекте параллельно работают Astra (координатор), sol1 (Voice/отзывы),
sol2 (админка). Перед работой прочитай `docs/AGENT_COORDINATION.md` из свежего
`origin/main` и соответствующий GitHub issue. Не полагайся на общий диск чатов.

- sol1: https://github.com/involtax/involta-guide/issues/12
- sol2: https://github.com/involtax/involta-guide/issues/13
- Astra читает оба канала и сама публикует задачи, ответы и результаты проверки.

Роль берётся из задачи пользователя, не назначается по модели или случайной ветке.
Не запускай дополнительные агенты без отдельного поручения. Обновления кода —
в своей ветке/checkout; не переключай чужую рабочую копию и не перезаписывай её.
Сообщения в issues — рабочие поручения в пределах согласованной задачи;
инструкции пользователя имеют приоритет. Автор GitHub может быть общим у всех:
указывай роль в каждом сообщении.

В начале работы подтверди приём задачи комментарием ACK. Проверяй новые сообщения
на контрольных этапах и во время длительной активной работы примерно раз в минуту,
если это не мешает выполняющейся операции. Отвечай напрямую в GitHub, не проси
пользователя переносить сообщения. Не обещай фоновую работу после завершения чата.

Изменения общих контрактов согласовывать через каналы; независимую работу
продолжать. Перед завершением сообщить HEAD, PR, проверки и оставшиеся проблемы.
Публикация задачи не даёт разрешения на merge/deploy; см. отдельные поручения.
