# Разработка

1. Используйте Node.js из `.nvmrc` и `npm ci`.
2. Создайте локальный `.env.local` по `.env.example`; реальные ключи не коммитьте.
3. Настройте PostgreSQL: `npm run setup:local`, `npm run db:up`, `npm run db:migrate`, `npm run db:seed`.
4. Запустите `npm run dev`; очередь — отдельным процессом `npm run worker`.
5. Перед отправкой выполните `npm run check`, `npm test`, `npm run build`. Для изменений интерфейса и пользовательских сценариев — `npm run test:e2e`.
6. Форматирование: `npm run format`. Изменяйте зависимости через npm с обновлением lockfile.

CI не использует production-секреты и не обращается к живому OpenAI API. Браузерные тесты используют временные схемы PostgreSQL, тестовый микрофон и случайные одноразовые учётные данные. В CI браузер устанавливает Playwright; локально можно использовать `/usr/bin/chromium` либо `CHROMIUM_PATH`.

Сохраняйте разделение черновика и публичной версии. Сохранение отзыва, одобрение, принятие предложения и публикация — разные операции. Любое автоматическое изменение публичного топа требует отдельного согласования продукта.

Не помещайте в Git дампы рабочей PostgreSQL-БД, аудио посетителей, секреты, `.env.local` и содержимое `var/`. При изменении схемы существующей БД предусмотрите миграцию и сохранение данных.

SQL-миграции добавляйте в `migrations/` отдельным следующим файлом. Применённые миграции нельзя редактировать: проверяются контрольные суммы. Тестам нужен `TEST_DATABASE_URL`. Для production используйте отдельную тестовую БД.

География: `locations` — единая модель городов, районов и курортов. Основная иерархия должна оставаться без циклов. Существующие ID и канонические URL сохраняйте; для старых адресов используйте перенаправления. Не создавайте копии ресторана ради включения в подборку надлокации. Подробнее: `docs/locations.md`.

Публичный HTML рендерится в `lib/public-*.mjs`, самостоятельные браузерные скрипты — `public/`. React-компоненты предназначены для админки. Не добавляйте React/Next runtime в публичные страницы. Для запуска нужен `npm start` / `npm run dev`, а не прямой `next start`: `scripts/server.mjs` разделяет публичный HTML и административный обработчик.
