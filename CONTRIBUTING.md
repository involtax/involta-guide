# Разработка

1. Используйте Node.js из `.nvmrc` и `npm ci`.
2. Создайте локальный `.env.local` по `.env.example`; реальные ключи не коммитьте.
3. Запустите `npm run dev`; очередь — отдельным процессом `npm run worker`.
4. Перед отправкой выполните `npm run check`, `npm test`, `npm run build`. Для изменений интерфейса и пользовательских сценариев — `npm run test:e2e`.
5. Форматирование: `npm run format`. Изменяйте зависимости через npm с обновлением lockfile.

CI не использует production-секреты и не обращается к живому OpenAI API. Браузерные тесты используют временную БД, тестовый микрофон и случайные одноразовые учётные данные. В CI браузер устанавливает Playwright; локально можно использовать `/usr/bin/chromium` либо `CHROMIUM_PATH`.

Сохраняйте разделение черновика и публичной версии. Сохранение отзыва, одобрение, принятие предложения и публикация — разные операции. Любое автоматическое изменение публичного топа требует отдельного согласования продукта.

Не помещайте в Git рабочую SQLite-БД, аудио посетителей, секреты, `.env.local` и содержимое `var/`. При изменении схемы существующей БД предусмотрите миграцию и сохранение данных.
