# Безопасность

OpenAI API вызывается только с backend. Единственный источник ключа — серверная переменная `OPENAI_API_KEY`; при деплое передавайте её приложению и воркеру через настройки сервера или менеджер секретов. Для сборки и CI ключ не требуется.

Не добавляйте реальные ключи в исходники, GitHub Actions YAML, логи, скриншоты или Git. `.env.example` содержит только пустые значения секретов. При утечке отзовите ключ у провайдера и замените его в окружении; одного удаления из последнего коммита недостаточно.

Для публичного запуска настройте HTTPS, `COOKIE_SECURE=true`, сильные `ADMIN_PASSWORD` и `SESSION_SECRET`, корректный `SITE_URL`, резервное копирование БД и аудио. Reverse proxy должен заменять входящий `X-Forwarded-For`.

Сообщайте об уязвимостях владельцу репозитория приватно; используйте private vulnerability reporting GitHub, если оно включено. Не публикуйте ключи, пользовательские аудиозаписи и персональные данные в публичных Issues.
