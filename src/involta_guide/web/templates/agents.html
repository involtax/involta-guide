Подключите один раз.

Добавьте адрес MCP в настройках совместимого клиента. После подключения ассистент увидит оба инструмента и описание их параметров.

В ChatGPT Plugins: «+» → Add custom MCP server → адрес выше → без авторизации → Create as a plugin. Возможность подключения зависит от настроек аккаунта и рабочего пространства.

Пример конфигурации 
{"mcpServers": {
  "involta-guide": {
    "url": "{{settings.url('/mcp')}}"
  }
}}

Названия настроек зависят от клиента. Для удалённого сервера выберите Streamable HTTP, авторизацию — без входа.

Публикация этой страницы не подключает гид ко всем GPT автоматически: доступными инструментами управляет приложение, в котором работает ассистент.
