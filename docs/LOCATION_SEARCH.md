# Выбор локации

По прямому решению владельца поиск работает локально по небольшому каталогу.
**Совпадения только по названию самой локации.** Регион, родитель, тип, slug и
алиасы не участвуют в поиске. Подпись с регионом/типом нужна лишь для различения
одноимённых мест в выдаче.

Видимая подпись над поиском на главной удалена; скрытая label даёт полю имя
«Выбор локации». Общий шаблон виджета сохраняет видимые подписи в админке.
Под выбором локации всегда лента «Жизнь кипит». Публичной формы поиска,
страницы выдачи и пагинации нет. Любые параметры главной перенаправляются
308 на чистую `/guide/`; ссылки с поисковыми параметрами не создаются.

## Загрузка и хранение

```text
GET главной → один GET /guide/api/locations/catalogue → JSON → индекс в памяти
                                                        → ввод без сети
```

Каталог загружается одним отдельным fetch при открытии главной, без cookies,
с пределом ожидания 5 секунд. В HTML списка нет. Ответ — массив объектов:

```json
[{"name":"Иваново","location":"ivanovo","context":"Ивановская область"}]
```

`location` хранит только slug, без повторяющегося `/guide/`; префикс берётся
из `data-location-base` при переходе. Для городов в context нет слова «Город».
У остальных типов сохраняется уточнение вида «Район · …». Только name участвует
в сопоставлении; context используется для подписи.

HTTP-кеш: ETag по содержимому ответа, `public, max-age=0, must-revalidate`.
При повторной загрузке браузер проверяет снимок условным запросом: неизменившийся
каталог получает 304 без тела, после изменения имени/состава/порядка — новый JSON.
На каждую такую проверку сервер читает каталог одним SELECT, без общего кеша
или TTL. API не выставляет cookies, не считает хиты и не запускает наполнение.

После получения данных индекс живёт в памяти страницы. Нормализация названий
и триграммы вычисляются один раз. При вводе нет запросов, debounce и «Ищем…»;
готовая выдача появляется до следующего кадра. Если ввод начался раньше ответа,
после загрузки используется актуальный текст и фокус; очищенный или потерявший
фокус список сам не раскроется. При ошибке/неверном JSON/таймауте виджет
показывает сообщение с предложением повторить загрузку кнопкой «Выбери».
Фокус и каждая буква не повторяют неудавшуюся загрузку; повторный клик или
Enter после ошибки делает одну новую попытку, без параллельных запросов.

Открытая страница хранит свой снимок до обновления; доступ к выбранной странице
проверяется сервером. LocalStorage, фонового опроса и дополнительных сервисов нет.
Служебные поля, содержимое подборок, админские данные и алиасы не передаются.

Видимость повторяет PUBLIC-правило: активные listed-локации, наполненные активные
локации и их полезные активные предки. Одним SELECT сервер задаёт исходный порядок:
готовые подборки, приоритет, name/id. Служебные признаки ранжирования не публикуются.

## Правила поиска

- Одна–две буквы: начало полного названия. От трёх: вхождение в любое место
  названия, все введённые слова должны присутствовать, порядок слов свободный.
- Регистр, е/ё, Unicode NFKC и разделители нормализуются.
- Выше точное название, затем начало слов, затем прочие вхождения;
  при равенстве сохраняется исходный серверный порядок.
- Если прямого совпадения нет, проверяется английская раскладка (`cjxb` → «сочи»),
  затем для запросов от четырёх символов — триграммная похожесть названия от 0,45.
  Это тоже локальные вычисления, без запросов и дополнительных библиотек.
- Подсказок не больше шести. Очистка ввода схлопывает блок. Потеря фокуса плавно
  схлопывает список с сохранением текста; повторный фокус мгновенно раскрывает
  подсказки из памяти. Escape сохраняет ввод/состояние. Крестик очищает и возвращает фокус. Первый вариант
  автоматически не выбирается; стрелки/Enter, мышь и touch открывают страницу.
- «Выбери ↓» раскрывает подсказки; при пустом поле показывает первые шесть
  локаций в серверном порядке. Повторный клик сворачивает список. Enter без
  выбранной подсказки раскрывает список, переход выполняется только по выбору.
  Публичный контрол — div с безымянным input, а не GET-форма; без JS он не
  отправляет запросы и не создаёт страницы выдачи. Ссылки «Все результаты» нет.
- IME не меняет выдачу до завершения композиции. Названия выводятся текстовыми
  узлами; `<script>`/HTML внутри названий не исполняются.

`location-index.js` отделён от DOM-адаптера. Локальная autoComplete.js 10.2.10
(Apache-2.0, 9 367 байт / ~3,8 КБ gzip) управляет списком, ARIA и выбором.
CDN, сборки frontend и новых сервисов нет. Полнотекстовый SQL, pg_trgm и новая
миграция поиска больше не нужны; не выпущенная `location_suggestions` удалена.
Поиск не требует своей миграции. Текущий Guide Alembic — `readable_slugs`;
обновление адресов описано в [TRANSLITERATION.md](TRANSLITERATION.md).
Админский поиск не меняется.

## Внешний вид

[Эталон владельца](design/location-search/reference-morph.html) задаёт морфинг:
единая оболочка строки/подсказок, закрытая высота 80 px, радиус 40→34 px,
числовая высота за 420 мс, `cubic-bezier(.22,1,.36,1)`. Тени
`0 2px 7px rgb(0 0 0 / 3.5%)` → `0 4px 14px rgb(0 0 0 / 4.5%)`.
Панель проявляется за 180 мс со сдвигом −6→0 px. Кнопка #2861eb сжимается
132×54→122×50 px, радиус 27→25 px; надпись «Выбери ↓» 22 px на всех
ширинах. До 600 px ширина кнопки 114 px, поле 16 вместо 22 px. До 360 px
ведущая лупа скрыта, чтобы сохранить место для названия.

При закрытии панель сразу получает inert/aria-hidden, после анимации hidden;
повторное раскрытие разворачивает текущий переход. ResizeObserver отслеживает
содержимое, visualViewport ограничивает высоту списка. Поле прокручивается в
видимую область только при фокусе. Reduced-motion практически отключает переходы.
Реальная клавиатура iOS/Android требует проверки на устройстве.

## Замеры

В каталоге репозитория 1448 записей, из них 1318 listed. Публичный JSON с тремя
полями занимает 135 966 байт UTF-8, 20 278 байт при gzip (сжатие зависит от
HTTP-сервера). На локальном Chromium для 5001 названия: создание индекса ~20 мс,
медиана поиска 0,2 мс, p95 0,4 мс в серии 100 запросов. Это локальные замеры,
не гарантия времени на каждом телефоне. Браузерный тест проверяет результат
до первого следующего кадра после ввода после загрузки каталога и работу с отключённым интернетом.

[Самодостаточная демка](design/location-search/approved-demo.html) использует
реальные CSS, библиотеку, индекс и адаптер с небольшим тестовым списком.
Единственная загрузка каталога в ней эмулируется тестовыми данными, без внешнего
запроса и искусственной задержки. [История макетов](design/location-search/README.md).

## Повторное использование в админке

`location_search.html` — один шаблон виджета для главной и «Рядом» в редакторе
локации. CSS и индекс поиска общие. DOM-адаптер монтирует формы при загрузке и
после HTMX; обработчики viewport и ResizeObserver освобождаются перед удалением.
Публичный snapshot по-прежнему содержит только name/context/location. В закрытой
админке каталог дополнительно содержит числовой id; выбор отправляет его в
защищённый POST добавления. Нативная POST-форма использует Python-поиск, соответствующий клиентскому
индексу; их совпадение проверяется на реальном каталоге. Это служебное добавление
связи, публичных поисковых страниц оно не создаёт.
