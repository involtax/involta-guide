# GOLD: страница и авторство отзывов

Бейдж GOLD в шапке ведёт на `/guide/gold`. Логотип отдельно ведёт на главную.
Страница открыта всем; её посещение не выдаёт GOLD.

Источник статуса — `vip_visitors`: запись с `visitor_id` и `level > 0`.
В отзыве уже есть `reviews.visitor`, полученный из cookie `guide_visitor`
при отправке. При чтении ленты вычисляем `author_is_gold` через `EXISTS`
по идентификатору **автора**, а не текущего читателя. Отдельного поля GOLD
у отзыва нет. Миграции не нужны.

Выдача/снятие статуса меняет оформление всех отзывов автора, включая старые,
при следующем чтении. Повторное распознавание не меняет привязку посетителя.
Очистка cookie или другой браузер создают другого посетителя; старые отзывы
сохраняют исходную привязку. Это анонимная идентичность устройства, не аккаунт.

- GOLD и имя: корона перед именем.
- GOLD без имени: только корона.
- Без GOLD: имя, если распознано; иначе строка автора отсутствует.

Шапка и отзывы используют один SVG `web/static/gold-crown.svg`, цвет #f6c900,
наклон 18°. Серверный HTML и обновление ленты виджетом выводят одинаковый маркер.
API передаёт только вычисленный флаг; идентификатор автора в публичную ленту
не добавляется. Правила публикации/модерации отзывов остаются прежними.
