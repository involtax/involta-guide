# Ссылка для ассистентов в футере

В общий футер добавлена ссылка «Для ассистентов» на `/guide/for-agents` рядом
с существующей ссылкой проекта. Прежняя типографика, цвет и cookie первого
посещения сохранены. Отступ между ссылками — 24 px, перенос строк — 8 px.

Проверено браузером с настоящими шаблоном и CSS на 1440, 390 и 320 px,
для первого и повторного посещений: правильные подписи/адреса, без переполнения.
Скриншоты рендера: [1440 px](desktop-first.png) · [390 px](mobile-first.png) ·
[320 px](small-mobile-first.png) · [после знакомства с проектом](small-mobile-seen.png).
Это рендер текущего checkout, а не подтверждение деплоя на production.
