# Голосовой блок: четыре варианта

Статические предложения для выбора Алекса, 4 ноября 2026 года.
Состояние: **до начала записи**, постоянно видимая просьба и круглый микрофон.
Это макеты, не работающий виджет. Они не используют микрофон, внешние сервисы, API или БД.
В production ничего не изменено.

На каждом скриншоте широкая компоновка и телефон 390 px. Широкий фрагмент
показан в окне 760 px; это сравнительный стенд, не полный скриншот страницы.
Миниатюрная шапка и нижняя строка обозначают контекст сайта. Техническая
диагностика не включена в визуальный фрагмент; её удаление не предлагается.

| № | Направление | Отличие | Скриншот |
| --- | --- | --- | --- |
| 1 | Редакционный | Крупная пара Arial + Georgia, отдельная спокойная инструкция | [01.png](screenshots/01.png) |

Предпочтение автора макетов — вариант 1: повторяет типографический приём
заголовка города и сохраняет заметное приглашение. Вариант 3 подходит, если
нужен более спокойный финал страницы. Это рекомендация, не решение владельца.

Открыть `preview.html?variant=1` (параметр 1–4) или соответствующий отдельный HTML.
Файлы открываются локально, без приложения. Текст и кнопки — настоящий HTML/CSS,
скриншоты сняты Playwright/Chromium, не сгенерированы как рисунок.

Переснять из корня репозитория с установленными dev-зависимостями:

```sh
uv run python docs/design/voice-section/render.py
```

Источник визуальных правил: [VISUAL_STYLE.md](../../VISUAL_STYLE.md).
