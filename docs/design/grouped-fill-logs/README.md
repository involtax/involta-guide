# Один запуск наполнения в списке логов

`preview.html` — автономный HTML-макет согласованной компоновки. Без зависимостей.
Он показывает сокращённый пример; рабочий список содержит все запросы запуска.

Макет проверен в Chromium на 320/390 px touch, затем 1440 px:
[мобильный экран](mock-390.png), [широкий экран](mock-1440.png).

Браузерная проверка реального шаблона: `tests/e2e/test_grouped_fill_logs.py`.
Она сначала проходит 320/390 px touch, затем 1440 px, проверяет один пункт слева,
автоматическое появление дочернего исследования, переход к его прежнему URL/JSON
и отсутствие горизонтальной прокрутки. Данные тестовые, модель заменена FakeAI.
Production-генерация не запускается.

Скриншоты работающего шаблона с FakeAI: [пачка на телефоне](actual-group-390.png),
[одна запись в списке](actual-sidebar-390.png), [пачка на desktop](actual-group-1440.png).

Исходные реальные 20 логов Набережных Челнов используются в unit-проверке только
как компактные публичные метаданные: без промптов, ответов провайдера и секретов.
Они сворачиваются в один запуск; отдельный более поздний запрос остаётся отдельным.

Контракт и совместимость: [LOGS.md](../../LOGS.md#наполнение-страниц).
