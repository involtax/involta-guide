# Гибридный поиск

Владелец согласовал поиск локаций и опубликованных ресторанов, морфологию,
опечатки, варианты написания, фоновый запрос и бессрочную историю с IP.
Смешивание поручено реализовать и показать для оценки.

[Интерактивная HTML-демка](index.html) — автономный файл, реальные CSS/JS виджета,
тестовые названия/отзывы. Словарь локаций загружается мгновенно; фоновые ответы
эмулируются после паузы ввода, с дополнительными 180 мс условной сети. Для
примеров заранее вычислены ответы настоящего Python-алгоритма; произвольный
текст в демке использует упрощённое совпадение. Запросы и IP не сохраняются,
внешних запросов нет. Выбор сообщает о переходе, реальная навигация отключена.

Попробовать: «Пушкин», «Пушкни», «Пушкин Туле», «в Иванове», «питер», «ples».

Демка: [1440 px](desktop.png) · [390 px](mobile.png) · [320 px](small-mobile.png).
Реальное тестовое приложение с PostgreSQL: [1440 px](implemented-desktop.png) ·

Скриншоты содержат тестовые рестораны; это не production-данные.

Один список до 8 вариантов. Точная релевантность важнее типа; внутри равной
точности — две локации, затем ресторан. При наведении/выделении клавиатурой
уже показанные позиции сохраняются. Подпись ресторана — «Ресторан · город».
