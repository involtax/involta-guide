# Главная: «Жизнь кипит»

Владелец утвердил макет в чате и поручил внедрить его в PR.

- Рубрика: «Еда. Люди. Качество.», без смены регистра.
- Подпись «Куда отправимся?» и описание под поиском удалены.
- «Выбери ↓» раскрывает подсказки; переход только после выбора, публичной формы
  и страниц выдачи нет.
- Вместо сетки городов — 10 свежих публичных отзывов, новые сверху.
- Город курсивом слева, время справа; вся строка ведёт в город.
- Тонкие линии только между отзывами; после последнего и над футером их нет.
- Ресторан выводится в будущем, после появления реальной привязки.

[Автономный макет](index.html) содержит явно помеченные демонстрационные отзывы.
Единственный запрос каталога поиска эмулируется, ссылки отзывов ведут в города.

[Макет: компьютер](desktop.png) · [телефон](mobile.png) · [320 px](small-mobile.png).

Реальное приложение с отзывами из тестовой PostgreSQL:
[компьютер](implemented-desktop.png) · [телефон](implemented-mobile.png).
Это тестовые отзывы; production-данные в эти скриншоты не входят.

Реализация: `web/templates/directory.html`, `web/static/home.css`,
`VoiceReadModel.latest_public_texts()`. Лента выводится сервером одним SELECT;
публикация/статусы и PUBLIC-видимость локаций берутся из существующих таблиц.
