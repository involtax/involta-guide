# «О проекте»: утверждённый дизайн

Алекс утвердил этот вариант 5 ноября 2026 года после просмотра мобильного макета.
Страница посвящена голосовым отзывам: три блока, крупные заголовки Arial +
курсивная Georgia, чёрные описания, тонкие разделители. В шапке «О проекте»
вместо «Россия». Номеров, общего верхнего заголовка и содержимого после третьего
блока нет. На главную ведёт логотип.

- [Утверждённый автономный HTML-макет](approved.html).
- [Реализация, 390 px](mobile-390.png).
- [Реализация, 320 px](mobile-320.png).
- [Реализация, 1440 px](desktop-1440.png).

Скриншоты реализации получены браузером с локально запущенным приложением и
тестовой PostgreSQL. Макет служит визуальным эталоном; runtime использует
`src/involta_guide/web/templates/about.html` и общий `style.css`.

Согласованные формулировки — продуктовый текст. Эта задача не реализует чат,
повторное распознавание или автоматическое влияние отзывов на рейтинг.
