# Вступления 50–100 символов: первое знакомство

Согласованный тон — простая разговорная реплика гостю, который приехал впервые
и ненадолго. Узнаваемая особенность помогает представить место; бытовые памятки
про адреса и парковку исключены. Еда и совет куда идти необязательны.

Примеры написаны агентом без платного API. Это редакционная работа и проверка
вёрстки, а не измерение качества production-модели.

`preview.html` — автономный HTML с текущими стилями сайта, без зависимостей.
[iPhone, 375 px](preview-375.png), [390 px](preview-390.png), [430 px](preview-430.png).

В последних трёх столбцах — число строк при штатном Arial 16 px. Длина включает
пробелы и пунктуацию. Диапазон промпта — 50–100 символов, ориентир 70–90.
На iPhone 375/390 px эти пять примеров занимают три строки, на 430 px — две.
На 320 px — три-четыре строки. Текст не обрезается, шрифт не уменьшается.

Браузерный тест `tests/e2e/test_short_city_intro.py` открывает настоящие страницы
через TestClient на изолированной PostgreSQL: сначала 320/375/390/430 px touch,
затем 1440 px, всего 25 сочетаний. Проверены диапазон длины, количество строк
и отсутствие горизонтальной прокрутки. Тест не создаёт заданий и не вызывает модель.

Данные: `samples.json`; измерения макета: `measurements.json`; реального шаблона:
`actual-measurements.json`. [Настоящий шаблон, 320 px](actual-medvezhegorsk-320.png),
[390 px](actual-medvezhegorsk-390.png).

## Все согласованные тексты

[20 вступлений](city-character-examples.md) и [JSON](city-character-examples.json).
Набор согласован и опубликован через закрытый API 14 ноября 2026 года.
Изменены только эти 20 локаций; остальные вступления этим обновлением не затронуты.
Для каждой записи проверены текст страницы, `og:description`, результат применения
и сохранность каталога ресторанов и изображений. Прежние тексты сохранены перед записью.

До публикации все 20 текстов проверены в HTML и CSS, прочитанных с production:
100 сочетаний — сначала 320/375/390/430 px touch, затем 1440 px. На 320 px —
3–4 строки, на 375 px — 3, на 390/430 px — 2–3, на 1440 px — 2; переполнения нет.
Измерения: `production-layout.json`. Это локальная проверка production-вёрстки.

Сам промпт сохранён в PR #107 и начнёт использоваться после его развёртывания;
публикация готовых текстов через API выполнена отдельно от деплоя кода.

Число символов само по себе не гарантирует количество строк при любых буквах,
шрифтах и масштабе. CSS-clamp, скрытого хвоста и автоматического обрезания нет.
