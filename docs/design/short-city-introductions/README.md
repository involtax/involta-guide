# Короткие вступления: ручная AI-симуляция

Примеры написаны агентом по новому промпту, без вызова платной модели. На production
они не записывались. Это проверка идеи, длины и вёрстки, а не доказательство, что
другая модель при каждом запуске выдаст такие же тексты.

`preview.html` — автономный HTML с копией текущих стилей сайта, без зависимостей.
[320 px](preview-320.png), [390 px](preview-390.png), [desktop](preview-1440.png).

| Город | Вступление | Символов с пробелами | Строк на 320 px |
|---|---|---:|---:|
| Набережные Челны | Широкая Кама, большие проспекты и вечер за столом. | 50 | 2 |
| Медвежьегорск | Между Онего и Заонежьем — время согреться за столом. | 52 | 2 |
| Анапа | От морского берега — к виноградникам и ужину. | 45 | 2 |
| Иваново | Из фабричных кварталов — за новыми вкусами Иванова. | 51 | 2 |
| Плёс | Волга, старые дачи и обед с видом на воду. | 42 | 2 |

Число символов включает пунктуацию. Тире — один символ. Примеры хранятся в
`samples.json`, первичные измерения макета — в `measurements.json`.

Браузерный тест `tests/e2e/test_short_city_intro.py` дополнительно открывает
реальные страницы через TestClient на изолированной PostgreSQL с этими текстами:
сначала 320/360/390/430 px touch, затем 1440 px. Всего 25 сочетаний; все вступления
поместились в две строки без обрезки, горизонтальной прокрутки и изменения шрифта.
При ширине 320 px область текста — 270 px, Arial 16 px, высота строки 25.6 px.

Из реального шаблона: [Медвежьегорск, 320 px](actual-medvezhegorsk-320.png),
[390 px](actual-medvezhegorsk-390.png). Измерения: `actual-measurements.json`.
Тест не создаёт заданий наполнения, не вызывает модель и не меняет production.

Лимит промпта — 55 символов. Одного количества символов недостаточно для
математической гарантии двух строк при любых буквах, шрифтах и пользовательском
масштабе. Проверенные примеры укладываются при штатном оформлении сайта;
CSS-clamp, скрытого хвоста и автоматического обрезания текста нет.
