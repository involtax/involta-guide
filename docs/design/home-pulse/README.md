# Главная: «Пульс:»

Владелец утвердил [полный HTML-макет](approved.html) и средний межстрочный
интервал **1.55**, затем поручил реализацию и PR. Макет содержит снимок публичных
отзывов production на момент согласования; это отдельный статический документ,
не источник данных сайта и не новая страница приложения.

Ресторан 20 px, город 15 px курсивом с подчёркиванием и стрелкой — одна строка.
Один отзыв — первый подтверждённый ресторан. Имя и дата справа в шапке,
на мобильном дата под именем; неизвестные данные пропускаются.
Общие поля страницы, поиск и футер сохранены.

## Реализация

- [1440 px](screenshots/home-desktop.png)
- [768 px](screenshots/home-tablet.png)
- [390 px](screenshots/home-mobile.png)
- [320 px](screenshots/home-small-mobile.png)

Скриншоты сделаны браузерным тестом реального приложения с PostgreSQL и
синтетическими отзывами. Длинные имя/название намеренно проверяют сокращение
без переноса и горизонтального скролла. Проверяются также отсутствие ресторана
и имени, переход всей строки в город, сохранение разделителей/отступов,
типографика и интерлиньяж.
