# Страница подключения MCP

По поручению владельца MCP содержит только Location и Restaurant, с отзывами
внутри ответов. Отдельная индексируемая страница объясняет подключение людям
и агентам. Новая страница следует существующей типографике гида: белый фон,
Arial и курсивная Georgia в заголовке, тонкие разделители, моноширинные примеры.

[Исходный макет](index.html) · [1440 px](desktop.png) · [390 px](mobile.png).
Это макет страницы, а не production. Реальные адреса и конфигурация строятся
приложением из SITE_URL/BASE_PATH. Контракт и ограничения — [MCP.md](../../MCP.md).

Реальное приложение, HTTP/Uvicorn: [1440 px](implemented-desktop.png) ·
[390 px](implemented-mobile.png) · [320 px](implemented-small-mobile.png) ·
[раскрытая конфигурация](implemented-config.png). Проверены отсутствие
горизонтальной прокрутки и ошибок JavaScript, адрес подключения и раскрытие примера.
