# Административные маршруты

Все пути ниже под BASE_PATH (`/guide`). Защищённые действия требуют действующую
admin-сессию, same-origin и CSRF. Вход `/admin`, выход `/admin/logout` сохранены.
Единый shell сохраняется; компактная лента отзывов описана в [ADMIN_REVIEWS.md](ADMIN_REVIEWS.md).

| Раздел | URL | Действия |
| --- | --- | --- |
| Обзор | `/admin` | Сводка и переходы |
| Локации | `/admin/locations`, `/admin/locations/{slug}` | Sidebar, настройки географии/навигации, отдельный POST `/intro` с revision |
| Полный бета-сброс | POST `/admin/locations/{slug}/reset-and-fill` | Название-подтверждение, request_key, content_epoch; только обычный город, флаг BETA_RESET_ENABLED |
| Рестораны | `/admin/restaurants`, `/admin/restaurants/{slug}`, `/admin/restaurants/{number}` | Город в пути, ссылка на публичную страницу в новой вкладке, рейтинг и данные карточки |
| Отзывы | `/admin/reviews`, `/admin/reviews/{slug}` | Города слева, лента справа; permalink `/{slug}/{number}` открывает страницу и якорь |
| Повтор доставки | POST `/admin/reviews/inbox/{event_id}/retry` | Повтор сохранённого ошибочного Voice event |
| Лог отзыва | `/logs/reviews/{slug}/{number}` | Приватные исходные ответы ASR, метаданные и доставка; только администратор |
| Аудио | `/admin/reviews/{slug}/{number}/audio` | Только администратор, no-store |
| Логи | `/logs`, `/logs/{slug}/{number}` | Неудачный первый запуск: новый запрос/тот же ответ; успешный: просмотр и переход к сбросу |
| Настройки наполнения | `/admin/settings/filling` | Промпт и модель одной операцией, без постановки заданий |
| Контакты / оценки | `/admin/contacts`, `/admin/ratings` | Существующие данные отзывов |
| Сессии | `/admin/sessions` | Управление административным доступом |

Редакторского раздела Алекс, attach и старой очереди Guide review нет. Запись под
admin-сессией становится обычным автоматическим GigaAM-отзывом. Канонические ЧПУ отзывов и сравнение
GigaAM/Parakeet из PR18 не заменяются UUID-ссылками. Удалённый отзыв/лог возвращает
404, а не новый объект с тем же номером.

## Путь выбирает экран, query задаёт его опции

Каждый раздел имеет отдельный GET-обработчик. `active_section` в контексте Jinja
задаётся обработчиком и нужен только для подсветки меню/выбора шаблона. Он никогда
не читается из query. Неизвестные параметры игнорируются: `/admin?tab=fill`,
`/admin?tab=reviews&review=123` и `/admin?anything=123` открывают обычный обзор
со статусом 200 без редиректов. Без сессии корень показывает вход, после входа — обзор.
Защищённые разделы без сессии возвращают 401.

В ресторанах город задаётся `/admin/restaurants/ivanovo`, поиск городов — `?q=`,
пагинация карточек — `?page=2`. Числовой сегмент `/admin/restaurants/123` остаётся
номером карточки (явный `int`-маршрут перед slug-маршрутом). Корень списка выбирает
первый наполненный город; `?location=...` больше ничего не выбирает. Неизвестный
slug в пути возвращает 404. Существующий город без ресторанов показывает ноль
карточек. Поиск фильтрует sidebar, сохраняя явно выбранный город справа.
Переход между городами сбрасывает страницу, сохраняя поиск; пагинация сохраняет
город и поиск. Ссылка «Открыть страницу локации ↗» открывает `/{slug}` в новой
вкладке (`noopener noreferrer`, без HTMX), включая просмотр отдельной карточки.

Удалены `/admin/voice`, все его дочерние GET/POST aliases и `/api/admin/audio/{uuid}`,
UUID-редирект `/admin/voice/legacy/{uuid}`, конвертер старых локальных номеров Voice
и дублирующий обработчик контактов. Эти старые пути отвечают 404, таблиц
соответствия и временных редиректов нет. Канонические pending-записи остаются
`/admin/reviews/submission/{reference}`; их аудио — `/admin/reviews/media/audio/{reference}`.
Модерация, сравнение ASR, обычные редиректы после POST и логика Voice не меняются.

## Переход и ручная проверка

Миграций БД и изменений nginx нет: после обычного обновления приложения новые
ссылки используют пути выше, старые aliases сразу недоступны. Сохранённые в браузере
закладки с `?tab=` откроют обзор; закладки с `?location=` — первый наполненный город.
Виджет и дизайн админки сохраняются.

1. Войти через `/admin?tab=fill`: открыть обзор, затем «Настройки наполнения» через меню.
2. Открыть `/admin/restaurants/ivanovo`, проверить выделение города и публичную
   ссылку: новая вкладка `/{slug}`, админка остаётся на прежнем месте.
3. Набрать поиск города, перейти в другой город и на вторую страницу списка
   с >20 ресторанами: в адресе город в пути, только `q`/`page` в query.
4. Проверить `/admin/restaurants/not-a-city` → 404 и старые `/admin/voice/...` → 404.
5. Открыть актуальный отзыв через `/admin/reviews`, проверить аудио, обе модели,
   переход к запуску и доступность обычной формы решения. Проверять сохранение
   решения только на тестовом отзыве; GET не запускает обработку.
6. Повторить переходы на мобильном экране, обычной загрузкой, HTMX и кнопкой «Назад».

Ручная проверка и порядок перехода: [BETA_CORE_RUNBOOK.md](BETA_CORE_RUNBOOK.md).

Наполнение и модели без денежного учёта: [FILLING.md](FILLING.md).
