# Рыбинск: остановка первого наполнения из-за региональной ссылки Яндекса

Проверено 14 ноября 2026 года. Production на момент диагностики —
`eed17d5bbdf4bf8d78e6e6bd99d543c4170f382c`; промпт вступлений из PR #107 ещё не развёрнут.

## Что произошло

- Нажатие публичной кнопки создало два задания 14 ноября в 19:55:36 UTC
  (22:55:36 UTC+3): независимые вступление и поиск ресторанов.
- [Вступление /1](https://involta.ru/guide/logs/rybinsk/1) завершилось и записалось.
- [Поиск /2](https://involta.ru/guide/logs/rybinsk/2) получил завершённый ответ модели
  с 28 кандидатами; ответ сохранён. Этап занял примерно 5 минут 15 секунд.
- В 20:00:55 UTC проверка `Discoveries` отклонила `restaurants.4.mapsUrl` у «Рощи»:
  `https://yandex.com.ge/maps/org/roscha_vikonda/97317027367/`.
  Это рабочая региональная страница Яндекс Карт того же ресторана в Рыбинске,
  ул. Бабушкина, 29. Имя домена не означает другую географию ресторана.
- Общий валидатор `RestaurantInput.maps` разрешал несколько доменов Яндекса,
  но не `yandex.com.ge`. Весь ответ проверяется до применения, поэтому ни одна
  из 28 заготовок не записалась и исследование ресторанов не началось.
- Статус публичного наполнения стал `failed`, `can_start=false`; в UI появилось
  `AI response validation failed`. Публичный повтор после завершённой попытки
  намеренно не запускается автоматически: повтор доступен администратору в логе.

Контрольное чтение закрытого API: в городе 0 ресторанов, вступление сохранено.
Кнопка и опрос статуса работают; сбой находится в серверной проверке данных.

## Исправление

В существующий точный список разрешённых хостов добавлен `yandex.com.ge`.
Общий валидатор используется и поиском кандидатов, и заполнением карточек.
Ссылка сохраняется без переписывания пути, ID организации или источников.
HTTPS, отсутствие учётных данных и проверка точного хоста сохранены;
поддельные домены вида `yandex.com.ge.evil.test` отклоняются.

Схема БД, промпты, правила публикации и публичного повтора не изменены.

## Воспроизведение и проверки

Полный ответ из 28 мест сохранён только локально. На нём воспроизведены ошибка
до исправления и успешное сохранение всех 28 заготовок с созданием 28 заданий
`research` после исправления. После одной локальной подставной полной карточки
статус становится `ready`, ресторан появляется на странице, блок запуска исчезает.
Это проверка кода, не утверждение о проверенности ресторанов из реального ответа.

В Git включён только минимальный искусственный пример
`tests/fixtures/regional-yandex-discovery.json`: два вымышленных ресторана,
тестовые источники и два домена Яндекс Карт. Integration-тест проверяет применение
всего списка, постановку исследований и переход публичного статуса в `ready`.
Полный production-ответ и сетевая трасса в Git не публикуются.

Прошли 29 unit/integration-проверок, включая публичную кнопку и отрицательные
примеры ссылок. Отдельный браузерный сценарий проверяет мобильный touch на
320/390 px, затем desktop: один POST, ожидание, опрос, автоматическая перезагрузка
и появление сохранённого ресторана. Модель в тестах не вызывается.

## Восстановление production после развёртывания исправления

Открыть [Рыбинск /2](https://involta.ru/guide/logs/rybinsk/2) с правами администратора
и нажать **«Переобработать тот же ответ»**. Сохранённый результат поиска можно
использовать повторно; новый поиск не требуется. Проверка актуальности города
и защита от параллельного запуска остаются включены.

Успешное применение сохранит заготовки и запустит обычные отдельные AI-исследования
ресторанов. Только пригодные карточки с оценками попадут на публичную страницу.
В рамках диагностики production не изменялся, повтор и новые AI-запросы не запускались.
