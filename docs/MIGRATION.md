# Схема и переход

Актуальная архитектура, конвертер и rollback описаны в [CURRENT_STATE.md](CURRENT_STATE.md).
Старая цепочка Node/Python migrations и требования сохранять историю страниц удалены.
Свежая установка: `alembic upgrade head`, затем `guide seed`.
Существующая установка: контроллер production-деплоя делает backup перед конвертацией;
прямой запуск старого образа на новой схеме не поддерживается.
