# Пересборка подборки

Первичное наполнение и пересборка используют JobService._queue_generation и
JobService.process: одинаковый сохранённый промпт, модель и подстановка географии.
Текущий каталог не передаётся в промпт и не влияет на поиск. Каждый запуск
сохраняется в логах локация/номер.

Администратор запускает POST /admin/locations/{slug}/rebuild с CSRF. Для одной
локации допустим один активный запуск; публичная кнопка по-прежнему доступна
только до первого наполнения. Пересборка не очищает страницу, не блокирует
голосовой контур, не меняет content_epoch и не вызывает Voice reset.

При публикации в транзакции сверяются lease и baseline_revision. Рестораны
сопоставляются внутри локации по организации Яндекс Карт, затем точному
нормализованному названию (регистр, пробелы, ё/е). Неоднозначность останавливает
публикацию. Существующие ID, административная звезда и review_score сохраняются.
Новые рестораны добавляются. Не вошедшие в топ остаются в каталоге с active=0.
Отзывы, их решения, голоса, исходные аудио, очереди и логи не удаляются.

Ручная правка страницы во время запроса отменяет автоматическое применение,
но ответ остаётся в логе. Ошибка поиска/валидации также оставляет страницу прежней.
Полный сброс удалён из интерфейса и маршрутов. Старые задания reset больше
не исполняются штатным production worker.

В Reviews2 текущий успешный результат bugs/other задаёт вкладку автоматически.
Классификация не является согласием на изменение текста/каталога/голосов.
Категория ok ожидает ОК; смена исходного текста возвращает запись в «Новые».
