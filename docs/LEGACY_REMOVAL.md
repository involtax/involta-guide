# Реестр легаси и временных механизмов под удаление

Обновлён: 2026-11-02.

При добавлении старого адреса, формата или временного обходного решения обновляем
этот файл. Для каждой записи нужны причина сохранения, места в коде, условие
удаления и проверка результата. Запись здесь не означает, что механизм уже можно
удалить. После удаления отмечаем дату, коммит и выполненные проверки.

Статусы: **ожидает**, **на пересмотр**, **удалено**.

## LEG-001. Старые UUID-адреса логов

**Статус: ожидает.** `/guide/logs/<uuid>` и `/guide/logs/<uuid>.json` пока
перенаправляют на `/guide/logs/ivanovo/1` и соответствующий JSON. Старые ссылки
уже отправлялись пользователю.

Код: [public.py](../src/involta_guide/web/routes/public.py), обработчики
`public_log` и `public_log_json`. В `public_log` также есть действующий список
города `/guide/logs/ivanovo` — его сохранить.

Условие удаления: старые ссылки заменены, принято решение прекратить редиректы.
Проверка: короткие HTML/JSON-адреса и список города работают, старые URL больше
не поддерживаются. **Внутренние UUID и связи в БД не удалять.**

## LEG-002. Задания без сохранённого номера и модели

**Статус: ожидает.** Для старых заданий номер вычисляется по `created_at, id`,
модель берётся из сохранённого вызова, если он есть. При новом запуске города
старая история получает постоянные записи `audit.action=generation_run`.

Код: [jobs.py](../src/involta_guide/application/services/jobs.py),
`_queue_generation` — заполнение старой истории;
[audit.py](../src/involta_guide/infrastructure/ai/audit.py), `HISTORY` — резервные
`row_number`/`actual_model`;
[openai.py](../src/involta_guide/infrastructure/ai/openai.py), `generate` —
резерв модели для старого задания.

Условие удаления: заполнены метаданные всех старых заданий и счётчики городов,
закончился период отката на старое приложение. Одного нового запроса в Иваново
недостаточно — проверить остальные города. Проверка полноты, только чтение:

```sql
SELECT count(*) AS generation_jobs_without_metadata
FROM jobs j
WHERE j.kind = 'generate'
  AND NOT EXISTS (
    SELECT 1 FROM audit a
    WHERE a.action = 'generation_run' AND a.target = j.id::text
  );
```

После удаления проверить сохранность коротких ссылок, следующий номер повторного
запроса и фиксацию модели при смене настройки. Историю с `legacy=true` сохранить.

## LEG-003. Кнопка наполнения без авторизации

**Статус: ожидает.** Временная кнопка «Запарсить эти данные», публичные маршруты
запуска/статуса и автопубликация только на пустой странице запрошены владельцем
для первоначального наполнения. Переключатель `TEMPORARY_PUBLIC_FILL_ENABLED`.

Код и точный порядок удаления: [TEMPORARY_PUBLIC_FILL.md](TEMPORARY_PUBLIC_FILL.md).
Основные места: [public.py](../src/involta_guide/web/routes/public.py),
[location.html](../src/involta_guide/web/templates/location.html),
[public-fill.js](../src/involta_guide/web/static/public-fill.js),
[jobs.py](../src/involta_guide/application/services/jobs.py),
[worker.py](../src/involta_guide/infrastructure/jobs/worker.py),
[config.py](../src/involta_guide/config.py).

Условие удаления: закончено первоначальное наполнение, запуск перенесён в админку.
Сначала отключить режим и завершить/отменить его ожидающие задания. Проверить:
без входа запустить генерацию нельзя, из админки можно, страницы и аудит сохранны.
Метки `temporary_public_fill`, `temporary_public_fill_published` и источник
версии `public_fill` не удалять. Сохранить распознавание старых публичных логов.

## LEG-004. Параметры city/cities вместо location

**Статус: ожидает.** `tab=cities`, `city`, `cityId` принимаются для совместимости
со старыми ссылками и клиентами виджета.

Код: [admin.py](../src/involta_guide/web/routes/admin.py),
[api.py](../src/involta_guide/web/routes/api.py).

Условие удаления: клиенты/ссылки обновлены, отсутствие обращений со старыми
параметрами подтверждено. Одного истечения кеша виджета недостаточно.
Проверить запись/историю отзывов и переходы в админке с текущими параметрами.

## LEG-005. Отключение проверки SSH host key пустым значением или «-»

**Статус: ожидает.** Это временный режим; при реальном `DEPLOY_KNOWN_HOSTS`
проверка строгая. Текущий production использует строгую проверку.

Код: [ssh-release.sh](../deploy/ssh-release.sh), ветка `StrictHostKeyChecking=no`;
комментарии workflow, [DEPLOY.md](DEPLOY.md),
[test_ssh_transport.py](../tests/deployment/test_ssh_transport.py).

Условие удаления: актуальные host keys заданы во всех используемых окружениях,
принято решение полностью убрать временный режим. Проверить: пустое значение,
«-» и неверный ключ блокируют операцию; правильный ключ работает для deploy,
bootstrap, инспекции и смены пароля.

## LEG-006. Публичные подробные логи

**Статус: на пересмотр.** Сейчас это действующее требование владельца, а не
разрешение закрыть логи. Переключатель `PUBLIC_FILL_LOGS_ENABLED`.

Код: [public.py](../src/involta_guide/web/routes/public.py),
[public_logs.html](../src/involta_guide/web/templates/public_logs.html),
публичные ссылки в [location.html](../src/involta_guide/web/templates/location.html).

Возвращаться к удалению после решения владельца о завершении публичного режима.
Проверить: публичные адреса закрыты, административный аудит и JSON-экспорт
работают, вся история запросов и ответов остаётся в БД.

## Не считать мусором

- Сохранённые логи, ответы ИИ, номера запусков, версии страниц и связи между ними.
- Внутренние UUID: меняется адрес, а не первичный ключ.
- Исторические SQL/Alembic-миграции: их нельзя удалять из-за слова `legacy`.
  Они нужны для создания/переноса БД. Сворачивание миграций — отдельная задача.
- Два эквивалентных формата часов от ИИ: это обработка реальных входных данных.

## Удалённое

Пока нет. Для удаления записывать дату, ID записи, коммит и результат проверок.
