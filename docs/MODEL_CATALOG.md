# Модели наполнения

В `/guide/admin/settings/filling` выбирается поддерживаемая модель исследования.
Основная рекомендация — GPT-6.1 Sol; альтернативы и их назначение находятся в
`infrastructure/ai/catalog.py`. Выбранная модель сохраняется вместе с заданием,
смена настройки действует на будущие запросы. Недоступность модели сохраняется
в подробном логе OpenAI.

Каталог не содержит тарифов, сравнительных цен или расчёта стоимости. В Guide
и Voice сохраняются технические usage-токены и ограничения числа вызовов.
Денежный учёт отключён по решению владельца.

Контракт, диагностика лимита и переход: [FILLING.md](FILLING.md).
