# Выбор модели наполнения и цены

Админка → Наполнение: выпадающий список вместо свободного ввода API ID.
Тот же список доступен в карточке города, в очереди и при повторе из аудита.
Рекомендация для справочника — GPT-6.1 Sol как баланс качества и стоимости.
Сохранённая настройка при обновлении приложения автоматически не меняется.

Каталог: `src/involta_guide/infrastructure/ai/catalog.py`.
Цены сверены 02.11.2026 по официальным страницам:

- https://developers.openai.com/api/docs/models
- https://developers.openai.com/api/docs/pricing
- https://developers.openai.com/api/docs/models/gpt-6.1-sol
- https://developers.openai.com/api/docs/models/gpt-6-astra
- https://developers.openai.com/api/docs/models/gpt-6.1-terra
- https://developers.openai.com/api/docs/models/gpt-6-luna

Все предложенные новые модели поддерживают Responses API, structured outputs
и web search. Доступ конкретного проекта к модели проверяет сам OpenAI при запросе;
документация не является подтверждением доступности для каждого API-ключа.

В интерфейсе есть простой пример сравнения, а не обещание цены за город:
10 000 оплачиваемых входных токенов + 5000 выходных + 5 поисковых вызовов.
Выход включает оплачиваемые токены рассуждений. Для Standard с коротким контекстом
без кеширования формула в USD:

`input_price / 100 + output_price / 200 + search_price_per_1000 / 200`.

Текущий провайдер использует `web_search_preview`. По официальным тарифам поиск
для reasoning-моделей стоит $10/1000 вызовов, а для non-reasoning GPT-4.1 —
$25/1000; поисковый контент GPT-4.1 preview не тарифицируется отдельно.
Если меняем инструмент поиска или режим обработки, обновляем этот расчёт
и подпись в интерфейсе. Для остальных моделей оплачиваемый поисковый контент
должен учитываться в числе входных токенов сценария.

Фактические размеры промта, ответа, рассуждений и число поисков отличаются.
Сравнительная цена не заменяет счёт OpenAI и не выдаётся за точную стоимость запроса.
Действующая оценка расходов в `ai_usage` отдельно использует `AI_PRICES_JSON`;
отображение таблицы не меняет бюджет или тарифы в учёте автоматически.

При изменении цен сверяем официальную страницу, правим каталог и дату проверки.
При добавлении модели проверяем поддержку веб-поиска и JSON-схемы. Сохранённые
задачи продолжают использовать свою зафиксированную модель.
