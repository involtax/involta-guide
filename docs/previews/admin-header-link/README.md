# Ссылка в админку в публичном хедере

Скриншоты локального приложения с тестовой сессией; это не production.
Ссылка показывается после серверной проверки сессии на публичных страницах,
в том числе в логах. На маршрутах `/admin` остаётся кнопка «Выйти».

- [Гость, 1440 px](guest-1440.png): ссылки нет.
- [Администратор, 1440 px](admin-1440.png).
- [Администратор, 390 px](admin-390.png).
- [Администратор, 320 px](admin-320.png).

Проверены главная и «О проекте» на 320/390/1440 px, отсутствие горизонтального
скролла/перекрытия логотипа, переход по ссылке и сохранение выхода в админке.
Интеграционные проверки также покрывают страницу города, публичные логи, 404,
недействительную/просроченную/отозванную сессию и персональные заголовки кеша.
