# Временное публичное наполнение

Флаг Guide `TEMPORARY_PUBLIC_FILL_ENABLED` закрывает и кнопку, и backend POST/status.
Маршруты под BASE_PATH:

- `POST /api/locations/{slug}/fill` — первая попытка обычного активного города.
- `GET /api/locations/{slug}/fill/status` — состояние текущего цикла.

До первой попытки доступна кнопка. Повторный клик возвращает состояние той же очереди.
При ошибке посетитель видит статус; новый запрос или проверку сохранённого ответа
заказывает администратор из конкретного лога. Успех отмечается `initialized_at`, а не
числом ресторанов. После успеха повторное наполнение возможно только полным бета-сбросом.
Надлокации и reset_pending не принимают запуск. Ни глобального, ни массового запуска нет.

Промпт/модель фиксируются в задании до работы worker. Background GET/polling продолжает
тот же ответ. Неизвестный исход платного POST автоматически не переотправляется.
Публичные логи отдельно управляются `PUBLIC_FILL_LOGS_ENABLED`.
