## Применение

Используется тот же файл data/prompts/review-analysis-v1.txt и прежняя JSON-схема.
Worker сохраняет промпт в каждом новом задании. Старые ответы и задания не
переписываются, новых платных запросов ради этой проверки не создавалось.
Проверки приложения с имитированным провайдером подтверждают работоспособность
загрузки промпта и обработки ответа, но не доказывают семантическое качество модели.

Новые отзывы по решению владельца публикуются сразу. После успешной категории
bugs/other скрываются. Уточнение промпта не устраняет окно до классификации и
не гарантирует обнаружение скрытой рекламы без явных признаков.

По уточнению владельца добрые истории вокруг еды остаются на сайте как humor.

3 other (67, 63, 61). Для 63 сохраняется оговорка о совпадении с каталогом.
Это ожидаемые категории по новому промпту, а не новые ответы production-модели.

| Дополнительный контроль | Ожидается |
|---|---|
| Друг сварил харчо, съел две тарелки, все гости в восторге | humor |

| Купи мой курс, а то суп убежит, ха-ха | other: реклама под видом шутки |

Для humor mentions пустой; даже ошибочно переданные моделью упоминания не должны
создавать рестораны и голоса. Автоматическая категория видна в отдельной вкладке
без ОК. Публичные ленты, API виджета и MCP продолжают показывать отзыв.
