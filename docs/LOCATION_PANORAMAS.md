# Панорамы локаций

Утверждён вариант 05 «Панорама». Первая иллюстрация — Плёс.
Справа от панорамы доступно секретное типографическое продолжение, только при ручной прокрутке.

## Обязательные требования для генерации и добавления

- Единственный итоговый формат — **AVIF**, параметр кодирования **`quality=65`**.
  Это настройка кодека, а не процент сохранённых деталей. Утверждённый результат
  получен Pillow 12.3.0: `format="AVIF", quality=65, speed=6`.
- Размер строго **2172 × 724 px**, пропорции **3:1**, прозрачность обязательна.
  Не заливать фон белым, не обрезать прозрачные поля и не менять размер холста.
- Основной объект справа. **По бокам рисунок мягко растворяется в прозрачность**,
  без жёстких обрезанных краёв.
- Базовая палитра — синяя акварель. Другие оттенки допустимы только при
  обосновании историей конкретного города. В PR кратко указывать историческую
  причину цветового отступления; произвольная смена палитры не нужна.
- В Git хранится **только итоговый AVIF панорамы**: никаких исходников PNG,
  WebP, резервных копий или альтернативных форматов этой иллюстрации.
  Временный исходник для генерации/конвертации держать вне репозитория.
  Скриншоты интерфейса в документации — отдельные проверочные материалы.
- Имя — канонический slug локации: `/guide/ples` → `ples.avif`.
  Для района использовать slug района, а не города.
- Каталог: `src/involta_guide/web/static/panoramas/<slug>.avif`.
  Нет реестра, записей в БД и fallback: браузер получает один AVIF.

Пример подготовки из временного исходника (Pillow с поддержкой AVIF,
инструмент подготовки, не зависимость приложения):

```python
from PIL import Image

image = Image.open("/tmp/ples-source.png").convert("RGBA")
assert image.size == (2172, 724)
assert image.getchannel("A").getextrema()[0] < 255
image.save(
    "src/involta_guide/web/static/panoramas/ples.avif",
    format="AVIF", quality=65, speed=6,
)
```

Перед PR проверить декодирование, размеры, прозрачность и мягкие края,
посмотреть страницу сначала на 320–390 px, затем на широком экране.
После тестов выпустить обычный релиз: добавление в Git само по себе не обновляет сайт.

Например, `ivanovo.avif` автоматически подключает иллюстрацию на `/guide/ivanovo`.
Файл определяется сервером по slug при рендеринге HTML; отрицательного кеша нет.
Удаление файла возвращает обычную страницу. Нет картинки — нет пустого блока,
запросов отсутствующего изображения или кода анимации на странице.

Текущий `ples.avif` — **162 663 байта**, утверждённое качество 65;
публичный адрес: `/guide/assets/panoramas/ples.avif`.
В браузерах без AVIF иллюстрация не отображается: запасных форматов нет.
Старые PNG в истории коммитов не переписываем.

## Геометрия и позиционирование

| Параметр | Значение |
| --- | --- |
| Исходный холст | **2172 × 724 px**, 3:1 |
| HTML `width` / `height` | `2172` / `724`, резервируют пропорцию до загрузки |
| Широкий экран, **651 CSS px и больше** | Ширина изображения = ширина viewport без вертикального scrollbar; высота = ширина / 3 |
| Мобильный экран, **650 CSS px и меньше** | **1000 × 333⅓ CSS px**, viewport вырезает видимую часть |
| Ширина блока | Весь viewport, без боковых отступов; текст сохраняет обычные поля страницы |
| Горизонтальный вынос из контейнера | `margin-left: (100% - viewportWidth) / 2` |
| Вертикальное наложение | `margin-top: -clamp(120px, 20vw, 280px)` после блока вступления |
| Примеры наложения | 390 px → **−120 px**; 768 px → **−153.6 px**; 1440 px → **−280 px** |
| Положение текста | Заголовок и вступление выше рисунка по z-index; белая тень у вступления |
| Прозрачность изображения | **0.9** |

На десктопе виден весь исходник, включая оба естественных края; автодвижения нет.
На мобильном первоначальный `scrollLeft = 1000 − viewportWidth − 120`:
при ширине 390 px это **490 px**, видимый участок исходника —
примерно **x = 1064.3…1911.4 px**. До правого края изображения остаётся
**120 CSS px = 260.64 px исходника**: основной объект справа виден,
а закругление края не попадает в начальный кадр.

После загрузки движется видимое окно: `scrollLeft` сначала уменьшается,
то есть пользователь смотрит всё левее по рисунку. Скорость **14 CSS px/с**.
Автоматический диапазон: `120…(1000 − viewportWidth − 120)`;
у узкого диапазона обе границы сходятся посередине. В пределах **55 px**
от разворота движение замедляется до **18%** скорости и меняет направление.
Нет скачка из конца в начало и дублирования рисунка.

## Ручная прокрутка и доступность

- Полный ручной диапазон: **0…(ширина всей полосы − viewportWidth)**. До обоих настоящих
  краёв можно дойти пальцем, перетаскиванием мыши, горизонтальным колесом,
  Shift+колесом, стрелками, Home и End. Полоса прокрутки скрыта.
- На сенсорном экране свайп, выбор оси и инерция нативные: их выполняет браузер.
  JS не захватывает touch pointer и не вызывает preventDefault для свайпа.
  Отмена Pointer Events браузером не обрывает прокрутку.
- Для мыши/колеса оттягивание за край даёт смещение до **66 px**;
  упругий возврат длится **440 ms**. На телефоне поведение края определяет ОС.
- После горизонтального взаимодействия автодвижение возобновляется через
  **1800 ms**, плавно из текущего положения, только если окно целиком в пределах города.
  В секретной части после **1000 ms** без взаимодействия начинается возврат к
  правой границе обычного автоматического диапазона, длительностью **900 ms**
  с плавным разгоном и торможением. Удержание пальца/мыши, инерция и упругий
  возврат задерживают отсчёт; скролл перезапускает его. Новое касание, колесо
  или клавиша прерывают возврат. В скрытой вкладке и при reduced motion возврата нет.
  Любое касание панорамы приостанавливает автоматику до отпускания и завершения
  прокрутки. Вертикальный жест прокручивает страницу. Фокус, hover и вертикальное
  колесо сами по себе не останавливают движение города.
- Кнопок паузы и воспроизведения нет: движение автоматическое.
  При `prefers-reduced-motion: reduce` автоматическое движение и JS-упругий возврат
  отключены. Ручная нативная прокрутка и её системная инерция остаются у браузера.
- В скрытой вкладке анимация не работает; при возвращении не догоняет время.
  На широком экране кадры анимации не запрашиваются.
- Без JavaScript картинка остаётся видна, доступна нативная горизонтальная
  прокрутка. Автоматики и упругого эффекта нет, начальный кадр — левый.

Только на страницах с панорамой убраны «Стоит зайти» и две верхние линии
перед первым рестораном. Разделители между ресторанами сохранены.
Вступление берётся целиком из БД; текст не обрезается автоматически.

## Главная: «Узнаёшь город?»

При каждой загрузке главная выбирает 7 случайных городов без повторов
из публичного каталога, для которых существует AVIF. Если их меньше семи,
показывает все в случайном порядке. Новые панорамы автоматически участвуют
в выборе; фиксированного списка городов нет. Названия берутся из БД. Нет новых
полей, копий картинок или отдельного реестра. Поиск остальных городов сохраняется.

- Заголовок блока: прямой гротеск 28 px. Названия: курсив Georgia 25 px.
- Без описаний. Весь AVIF вписывается в ширину карточки, высота автоматическая,
  пропорции 3:1; без обрезки, масок и увеличения. Верхний отступ изображения
  −36 px (выбранный вариант 2), строка названия имеет высоту 44 px.
- На мобильном карточки идут вертикально, от 700 px — три колонки.
- Мелкие движущиеся частицы скрывают название. Первый обычный клик или Enter
  раскрывает его, второй открывает город. Остальная карточка сразу открывает город.
- Без JS/canvas названия видны и работают как обычные ссылки. Системное уменьшение
  движения оставляет статичные частицы; скрытая вкладка и невидимые карточки не анимируются.
- Блок отзывов сохранён в серверном Jinja-комментарии `directory.html`.
  Главная не запрашивает и не отправляет отзывы в HTML; отзывы городов не меняются.

Проверка: `tests/e2e/test_home_panorama_cards.py` — реальные HTTP + PostgreSQL +
Chromium, 320/390/768/1440 px, полные изображения, спойлеры, переходы,
отключённый JS и reduced motion.

## Секретное продолжение

Один общий файл `/assets/secret-route.avif`: **6516 × 724 px**, 9:1, AVIF quality=65,
83 180 байт, белый фон. Это отдельный типографический макет; требования прозрачности
и 3:1 относятся к городским панорамам, а не к нему. Синий тонкий курсив и чёрная
рукопись, три сцены: «Любопытность :)», «Тсс…», «я досмотрел».

Файл подключён справа от городского изображения в одной flex-полосе, выровнен по вертикальному центру панорамы со смещением на 40 CSS px вниз.
Его высота — минимум из трети viewport и высоты панорамы за вычетом наложения вступления.
На телефоне каждая из трёх сцен помещается
по ширине экрана. Пропорция 9:1 сохранена, обрезки нет. HTML-размеры резервируют
место до загрузки; `loading="lazy"` позволяет браузеру отложить запрос.
На мобильном город остаётся 1000 px шириной. На десктопе город по-прежнему занимает
экран, продолжение доступно ручной прокруткой за его правым краем.
Автоматические границы вычисляются только по городскому изображению. Упругий эффект
применяется ко всей полосе, поэтому стык не расходится. Без JS работает нативный скролл.
Главная использует только городские изображения, без пасхалки.

CSS/JS панорам подключаются с версией релиза, чтобы старый кеш не помещал
пасхалку под городом: [правила кеширования ресурсов](ASSET_CACHE.md).
