# Контекст проекта и карта документации

Этот документ содержит сведения именно об Involta Guide. Общие инструкции
о процессе работы находятся в [AGENTS.md](../AGENTS.md).

Алекс — пользователь, автор и владелец проекта. «Показать Алексу» в документах
означает показать пользователю в текущем диалоге, а не искать отдельного
согласующего. Если другой участник явно представился, не приписывай ему
автоматически личность и полномочия владельца.

Стек: Python, PostgreSQL, серверный HTML/Jinja и HTMX; JavaScript используется
для браузерных функций, включая запись, воспроизведение и анимацию.
Структура приложения и команды запуска описаны в [README](../README.md).

Владелец называет текущий этап **бетой**, следующий — **альфой**.
Не меняем эти названия и этап без его решения. В бете диагностика процессов
и оригиналы аудио неудалённых отзывов доступны извне по решению владельца,
но секреты, cookies и сырые персональные метаданные не публикуются.
Для альфы предусмотрено закрытие логов/экспорта/аудио с сохранением доступа
агента по токену. Это план перехода, а не команда менять доступ сейчас;
детали — в документации логов и эксплуатации.
