Операция: research.
Исследуй ОДИН указанный ресторан для «Инвольта гида». Это может быть загородное место в гастрономическом направлении города. Верни JSON по схеме, сохраняя фактическое расположение, а не подменяя его городом-владельцем подборки.
Поле scope задаёт независимую операцию: card — только карточка, assessment — только оценка, all — оба блока. Незапрошенный блок верни null. Переоценка не должна переписывать описание и контакты.
Проверяй источники: официальный сайт/меню, карты, актуальные отзывы и независимые публикации. Подтверди конкретный адрес/филиал и действующий статус. Для отелей и комплексов проверь возможность поесть без проживания. Не путай одноимённые заведения. Неизвестные факты обозначай null; если доказательств недостаточно, status=needs_verification. Явно закрытое заведение: status=closed. Недоступность одного сайта сама по себе не означает закрытие. Карта только Яндекс, телефон в международном формате; неизвестные часы/координаты допустимы. Описание короткое, живое, предметное, без выдуманной дегустации и объяснения методологии. 
Оценка: восемь РАВНОВЕСНЫХ факторов, каждый целое 0–10 или null при отсутствии достаточных данных: food (еда), consistency (стабильность), identity (самобытность), localConnection (связь с местом), atmosphere (атмосфера), service (сервис), value (цена/результат), destination (ради визита). Одни и те же стандарты для всех городов. Для каждого фактора дай конкретное краткое обоснование, confidence и ссылки источников. Ноль — реальная оценка, а не отсутствие сведений. Не подставляй баллы ради полноты, не рассчитывай итог и место. Сервер вычисляет среднее восьми факторов и ранжирование. Предыдущие факты — контекст, не основание механически повторять прежние оценки. Только JSON.

Сначала карточка, затем оценка. Для all сначала установи название, предметное описание, точную карту, телефон и HTTPS-источники. Оценка опирается на этот же конкретный ресторан. Если обязательные сведения карточки не подтверждены, верни доступные факты, status=needs_verification и assessment=null; не оценивай заготовку. Для assessment исходная карточка уже заполнена: проверь её и верни только оценку, card=null. Если при all карточку удалось заполнить, но данных для факторов мало, верни неизвестные баллы как null с честными обоснованиями.
